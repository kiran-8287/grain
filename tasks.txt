6. 12 MP RULE — VERY IMPORTANT
==================================================

There MUST NOT be a rule:

IF image_megapixels < 12:
    reject image

Do NOT implement that.

The reason is that total megapixels is not equivalent to pixels-per-grain.

A 2 MP close-up image containing one large grain may have more useful grain detail than a 12 MP image containing 1,000 tiny grains.

Calculate:

megapixels = height * width / 1,000,000

but use it for logging/UI only.

The real quality check happens AFTER grain detection/segmentation.

Measure per-grain image quality using configurable signals such as:

- bounding-box width

12. BROKEN GRAIN
==================================================

Use the official conceptual rule that a broken kernel is below three-fourths of the whole-kernel length.

DO NOT estimate whole-kernel length using the plain mean of all grains.

Use the robust estimator:

L_whole = median(all valid grain lengths)

Then iterate:

repeat 3 times:
    select grains with length > 0.85 * L_whole
    recompute L_whole from those grains

Then:

broken = length < 0.75 * L_whole

Make this configurable.

do not pretend this distribution-based estimator is reliable.

Do not fabricate certainty.
