## Failure Type Taxonomy

Every image-level detection mismatch is classified into exactly one primary failure
type (and optionally secondary types) by the matcher in `evaluate_model.py`.

| Code | Name | Weight | Definition | Severity |
|---|---|---:|---|---|
| `MISSED_GRAIN` | Missed grain | 3.0 | A GT rice grain has no matching prediction at mask IoU ≥ 0.50. **Count-error driver.** | HIGH |
| `MERGED_GRAINS` | Merged grains | 2.5 | One prediction mask overlaps ≥ 2 GT masks at IoU ≥ 0.30 each. Watershed failure in classical CV, typical for touching-pair scenes. | HIGH |
| `SPLIT_GRAIN` | Split grain | 2.0 | One GT mask overlaps ≥ 2 prediction masks at IoU ≥ 0.30 each. Oversegmentation of cracks or chalk stripes. | MEDIUM |
| `FALSE_RICE` | False rice | 4.0 | A prediction is labelled `rice_grain` in a `no_rice` (G) image. **SAFETY-CRITICAL.** Zero tolerance. | CRITICAL |
| `FALSE_FOREIGN_MATTER` | False foreign | 3.5 | A rice cluster or chalky grain is labelled `foreign_matter`. Produces rejected lots that are actually clean. | HIGH |
| `DUPLICATE` | Duplicate detection | 1.0 | The same GT grain is matched by two predictions (mask IoU ≥ 0.50 to the same GT). Post-NMS cleanup issue. | LOW |
| `BAD_MASK` | Bad mask shape | 2.0 | Box IoU ≥ 0.50 (detection OK) but mask IoU < 0.50. Prediction finds the grain but draws the wrong contour. | MEDIUM |
| `LOW_CONFIDENCE` | Low confidence | 0.5 | Detection is correct (matched) but confidence < 0.50. Warning signal, not an error per se. | WARNING |

Weights (rightmost column of the plan) are used by `analyze_failures.py` to compute
a per-image composite failure score, which is then used to rank the top-10 worst
images for human triage.

## 9 Test Categories A–I (Failure Context)

Each evaluated image is bucketed into exactly one category. Failures are reported
both overall and per-category so iterative training knows exactly which density
regime to reinforce with synthetic data.

| Code | Name | GT grain count | Special properties |
|---|---|---:|---|
| A | single_isolated | 1 | no touching, no overlap, no FM |
| B | few_separated | 2–10 | no touching, no overlap, no FM |
| C | touching | 2–100 | at least 1 touching GT pair, no overlap, no FM |
| D | overlapping | 2–100 | at least 1 overlapping GT pair, no FM |
| E | dense | 50+ | no overlap flag required, no FM |
| F | rice_plus_foreign | 1+ | at least 1 `foreign_matter` GT instance |
| G | no_rice | 0 | also 0 FM instances (pure background / non-rice) |
| H | foreign_only | 0 | ≥ 1 FM instances (no rice) |
| I | mixed_difficult | 11–49 or multi-challenge | does not fit A–H cleanly |

Priority order inside `categorize_image()` is: H/G first, then F, D, C, E, A, B, I.
This ensures an image that could qualify for both "touching" and "dense" is
reported under the harder regime.

## Pre-Training Expected Failure Distribution (NOT MEASURED)

These are literature-derived *planning targets*, not measured values. They tell
`analyze_failures.py` what the "bad" direction is so it can raise a red flag if
a run deviates by more than 2×.

| Category | Expected dominant failure type | Expected fraction of total failures |
|---|---|---|
| A — single isolated | BAD_MASK (cracks, chalk) | ~3 % |
| B — few separated | DUPLICATE / LOW_CONFIDENCE | ~7 % |
| C — touching | MERGED_GRAINS (primary risk) | ~25 % |
| D — overlapping | MERGED_GRAINS + MISSED_GRAIN (occluded) | ~20 % |
| E — dense | MISSED_GRAIN (small grains) + DUPLICATE | ~25 % |
| F — rice plus FM | FALSE_FOREIGN_MATTER (rice mis-called FM) | ~8 % |
| G — no rice | FALSE_RICE (zero tolerance) | **must be 0** |
| H — foreign only | MISSED_GRAIN (FM) / FALSE_RICE (dust) | ~2 % |
| I — mixed | Composite of C/D/E/F | ~10 % |

If after Run 1, category C failure fraction is > 40 % (1.6× expected), the
training response is: add 500+ touching synthetic images and fine-tune for 30
more epochs. See docs/MODEL.md § 7 for the full iterative protocol.

## Recommended Response Actions (auto-suggested per-failure)

Hard-coded into `analyze_failures.py`. When a failure type is dominant within a
category, the script emits exactly one of the bullets below into the
auto-generated section of this file.

| If dominant failure is … | Script recommends … |
|---|---|
| `MERGED_GRAINS` in C | Add 500+ synthetic **touching** images, run fine-tune 30 epochs with `copy_paste=0.5` |
| `MERGED_GRAINS` in D | Add 500+ synthetic **overlapping** images, resume from best.pt |
| `MISSED_GRAIN` in E | Add 200+ synthetic **dense** and **very_dense** images; verify tile overlap is at least 128 px |
| `MISSED_GRAIN` in A/B | Check dataset quality: are there whole grains on the image edge being cut off? Re-train with 1280 imgsz. |
| `SPLIT_GRAIN` anywhere | Increase mask-IoU NMS threshold from 0.50 → 0.60; re-run evaluation. If still high, add mild dilation to GT masks during training. |
| `FALSE_RICE` in G (any amount) | **Stop.** This is a safety blocker. Re-train with explicit hard-negative mining of 500 non-rice backgrounds pasted into the train split. Do not ship until G reports 0. |
| `FALSE_FOREIGN_MATTER` in F | Lower the foreign-matter class weight in the training loss; add 200 clean-only (no FM) images with explicit class-balance sampling. |
| `DUPLICATE` in dense E | Increase `nms_threshold` from 0.3 → 0.45 in configs/thresholds.json; reduce conf from 0.25 → 0.20 to surface the lower-conf twin, then let mask-IoU NMS remove it. |
| `BAD_MASK` in A/B | Increase `imgsz` from 640 → 832; retrain. Grain boundaries need more pixels. |
| `LOW_CONFIDENCE` (any) | Fine-tune 20 more epochs at half lr with a higher `copy_paste` ratio. Or accept it: low-confidence grains are still usable for the analyst-facing UI and just display yellow. |
